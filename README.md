# Personal Portfolio Website

This is my personal portfolio website where I share a bit about myself, my work experience, skills, and projects.

## About

I created this website to have a place where I can show my experience and work outside of my resume. I also wanted to build something simple that I can update whenever I have new projects or experience to add.

## Built With

- HTML
- CSS
- JavaScript
- Bootstrap
- Bootstrap Icons

## How I Built It

I built the website using HTML, CSS, and JavaScript, with Bootstrap for the layout and responsive design.

I worked on the different sections of the website, including the About, Profile, Skills, Resume, Projects, and Contact sections. I also adjusted the layout and styling to make the website work well on both desktop and mobile.
